# NASA Astronomy Picture of the Day

Explore the cosmos through NASA's Astronomy Picture of the Day (APOD). Enter any date and discover the celestial wonder that was featured on that day.

## About

This web application connects to NASA's Astronomy Picture of the Day API, allowing users to browse through daily space images and videos. Each entry includes the title, description, and the actual image or video from that specific date.

## Features

- **Date Selection**: Choose any date to see that day's astronomy picture
- **Rich Media**: Displays both images and videos
- **Detailed Information**: Shows title and description for each entry
- **Clean Interface**: Minimalist design focused on the content
- **Responsive Layout**: Works on all screen sizes

## Technologies

- HTML5
- CSS3
- JavaScript
- NASA APOD API
